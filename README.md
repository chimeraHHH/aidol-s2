# AIdol S2 · 陪伴式运动凳

京东 Aidol 创造营 S2 的初始存档仓库，建立于 2026-10-16。

## 本次存档状态

本次存档仅含项目说明文档，没有应用或固件实现。以下内容依据赛前采购与装配方案整理，均为计划中的功能，尚未通过原型联调验收。硬件采购和装配实况以实物记录为准。

## 48 小时原型计划

1. 装配承重训练台/箱体、可拆坐垫、7 寸独立宠物屏与 Mac mini。
2. 编写 ESP32 采集固件，读取坐垫压力开关、解析体脂秤 BLE 广播，经 USB 串口发送占用、重量及有效阻抗数据。
3. 开发 Mac 本机串口桥接和宠物界面，完成状态展示、久坐计时、语音提醒与起身运动引导。
4. 接入 UVC 摄像头，优先实现深蹲或踏步中的一种动作识别及计数。
5. 联动宠物反馈与运动完成提示，演示“坐下—久坐提醒—起身训练—反馈”，整理源码与操作说明。

## 拟采用的第三方基础

- 主机与系统：已有 Mac mini / macOS。
- 设备：ESP32-S3、二线常开压力开关垫、HDMI 显示屏、UVC USB 摄像头、USB 数字音响、完整蓝牙体脂秤（方案指定小米体脂秤 2，XMTZC05HM）。
- 解析参考：ESPHome 的 xiaomi_miscale 开源组件。
- 通信接口：BLE、USB 串口、逐行 JSON、本机 WebSocket。
- 语音：本机语音或预录提示。
- 姿态模型和运行库待按 Mac 芯片及 macOS 兼容性选型；方案尚未指定云端大模型或 API。

体脂率展示按实际实现情况接入。若使用官方 App 实测后人工录入，会在界面中标明来源。实际选用的模型、组件、服务及其许可将在后续实现中补充记录。
