# 窝知 · 表情遥控台

独立的电脑遥控台与安卓手机显示屏。电脑选择状态或逗猫视频，手机全屏循环播放；适合从窝知网站添加入口或 iframe 嵌入。

## 素材与状态

| 按钮 | 原始表情视频区间 | 用途 |
| --- | --- | --- |
| 待机 / 睡眠 | 13–18 秒，5 秒 | 平时待机，闭眼与 ZZZ |
| 启动 / 唤醒 | 0–8.8 秒，8.8 秒 | 圆眼、眨眼、左右张望 |
| 称重 / 开心互动 | 8.8–13 秒，4.2 秒 | 猫咪上秤至示数稳定，眯眼与星星眼 |

另外 4 个游戏按钮对应完整视频：追逐小黑球、追逐小鱼、追逐寄居蟹、追逐彩色光点。所有素材来自用户提供的视频，仅转码及分段，未重绘。循环是视频播放结束后重新开始，素材首尾并非全部无缝。当前为手动遥控，不自动读取秤的传感器，不包含触摸计分逻辑。

## 使用

1. 电脑打开网站首页，点击 **连接手机**。
2. 安卓手机扫码，用 Chrome 等浏览器打开配对链接。
3. 手机点 **开始全屏播放**。播放页默认静音、完整显示画面，并尝试锁定横屏、申请屏幕常亮。
4. 电脑点击 3 个状态或 4 个游戏按钮；界面显示手机实际播放确认。也可暂停、回到睡眠、旋转画面、切换完整/铺满、开启声音。
5. 配对有效 24 小时。电脑刷新可恢复配对；手机当前标签刷新可恢复。过期后重新扫码。

浏览器可能要求手机再次点按才能允许声音或恢复全屏。右上角「···」提供操作。屏幕常亮和横屏锁定取决于浏览器支持；如无效，请调整手机自动锁屏设置。断网后当前已加载视频继续循环，网络恢复后自动读取最新指令。

## 网站嵌入

首页底部「嵌入网站」会生成当前站点的入口按钮和 iframe 代码。手机显示屏推荐独立浏览器标签打开。

## 本地运行

Node.js 22 或以上：

```sh
npm ci
# 复制 .env.example 为 .env.local，填写本项目独立 PostgreSQL 数据库的 DATABASE_URL
npm run build
npm start
```

默认端口 4173。首次 API 请求自动初始化本应用的 `wozhi_rooms` 表。数据库连接使用服务端环境变量，绝不交给前端。

## Vercel

从 GitHub 导入此仓库，Framework 选 Other；构建 `npm run build`，输出目录 `public`。设置加密环境变量 `DATABASE_URL` 为独立 PostgreSQL 数据库连接。`vercel.json` 配置 Node API 与 `/screen`、`/remote` 路由。

播放状态保存在 PostgreSQL 中，不依赖单个 Vercel 函数实例的内存。两端通过短轮询同步，手机约每 0.9 秒读取指令，实际切换延迟还取决于网络和视频加载。设备心跳约 2.5 秒更新，超过 12 秒无心跳视为离线。

## 配对权限

每次连接生成随机控制令牌与只读显示令牌。服务端只保存 SHA-256 摘要，显示端不能修改控制指令。手机配对凭证放在 URL fragment，读取后存入 sessionStorage 并移除 fragment（浏览器支持时）。不要公开配对链接。网页静态素材可公开访问；源码仓库与部署环境变量单独管理。

## 验证

```sh
npm test
```

`tests/api-integration.mjs` 在指定 `TEST_BASE_URL` 上验证配对、七个视频切换、权限隔离、心跳与非法输入；测试会创建有效期 24 小时的测试连接。

素材说明：视频的使用权沿用用户原始素材授权；此项目不附加对第三方视频素材的授权声明。

播放页首次点击直接请求整个显示容器全屏，即使视频仍在加载也不会丢失全屏手势。电脑切换只更新同一个视频元素，不退出全屏；意外退出后可直接点击底部恢复按钮。浏览器禁止的全屏仍需手机端手势，不能由远程指令绕过。
