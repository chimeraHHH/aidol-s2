# 猫咪体重与健康信息知识库 V1.0

## 1. 使用目的

本知识库供手机端问答 API 检索。API 根据用户问题及猫咪档案字段，返回体重参考、趋势解释、健康科普、补充提问和风险提示。

本知识库用于健康信息与趋势管理，不用于诊断疾病，也不能替代兽医检查。

## 2. API 可调用的猫咪字段

### 2.1 首次建档必填

| 字段 | 字段名 | 类型/选项 | 用途 |
|---|---|---|---|
| 猫咪 ID | `cat_id` | 字符串 | 绑定个体档案 |
| 名称 | `name` | 字符串 | 个性化回答 |
| 品种 | `breed` | 枚举 | 辅助解释成年体型 |
| 出生日期 | `birth_date` | 日期 | 计算年龄和生命阶段 |
| 日期准确度 | `birth_date_accuracy` | `exact/estimated` | 判断年龄可信度 |
| 性别 | `sex` | `male/female/unknown` | 选择性别参考范围 |
| 绝育状态 | `neuter_status` | `neutered/intact/unknown` | 评估增重风险 |
| 绝育日期 | `neuter_date` | 日期/空 | 分析绝育前后趋势 |
| 家庭类型 | `household_type` | `single_cat/multi_cat` | 判断单传感器数据归属风险 |

品种枚举：

- `DOMESTIC_CHINESE`：中华田园猫
- `RAGDOLL`：布偶猫
- `BRITISH_SHORTHAIR`：英国短毛猫
- `SIAMESE`：暹罗猫
- `OTHER`：其他
- `UNKNOWN`：不确定

### 2.2 建议字段

| 字段 | 字段名 | 类型/选项 | 用途 |
|---|---|---|---|
| BCS | `bcs_score` | 1–9/空 | 判断偏瘦、理想、超重或肥胖 |
| BCS 来源 | `bcs_source` | `owner/vet` | 区分自评与兽医确认 |
| MCS | `mcs_score` | 正常/轻/中/重度流失 | 评估肌肉情况 |
| 已知疾病 | `known_conditions` | 多选 | 调整体重变化解释 |
| 当前用药 | `current_medications` | 列表 | 解释食欲和体重变化 |
| 主粮名称 | `food_name` | 字符串 | 饮食追踪 |
| 食物类型 | `food_type` | 干/湿/混合/处方/其他 | 饮食描述 |
| 热量密度 | `calorie_density_kcal_100g` | 数值 | 计算实际热量 |
| 每日主粮量 | `daily_food_g` | 数值 | 计算实际热量 |
| 喂食方式 | `feeding_method` | 定量/自由采食/混合 | 分析过量摄入风险 |
| 零食水平 | `treat_level` | 无/少量/较多/未知 | 补充热量来源 |
| 活动水平 | `activity_level` | 低/中/高/未知 | 辅助解释能量消耗 |
| 目标体重 | `target_weight_g` | 数值/空 | 计算目标差值，优先使用兽医目标 |

### 2.3 设备与系统计算字段

| 字段 | 字段名 | 说明 |
|---|---|---|
| 稳定体重 | `stable_weight_g` | 单传感器取得的有效稳定体重 |
| 测量时间 | `timestamp` | 单次称重时间 |
| 测量置信度 | `measurement_confidence` | 0–100 |
| 当日代表体重 | `daily_weight_g` | 当日有效称量中位数 |
| 7 日趋势体重 | `weight_7d_g` | 最近 7 日平滑结果 |
| 30 日变化量 | `weight_30d_change_g` | 当前趋势与约 30 日前比较 |
| 30 日变化率 | `weight_30d_change_pct` | 变化量/历史基线 |
| 90 日变化率 | `weight_90d_change_pct` | 当前趋势与约 90 日前比较 |
| 个人稳定基线 | `personal_baseline_g` | 健康稳定阶段的历史体重 |
| 数据质量 | `data_quality_score` | 数据量、波动和置信度综合 |
| 进入次数 | `daily_session_count` | 每日猫窝使用次数 |
| 总停留时长 | `daily_total_duration` | 每日承重持续时间总和 |

单传感器不能自动获得重心、姿势、身份、体脂、肌肉量、心率、呼吸率或睡眠阶段。

## 3. 品种成年体重参考

| 品种 | 成年母猫参考 | 成年公猫参考 | 成熟特点 | 使用限制 |
|---|---:|---:|---|---|
| 中华田园猫 | 不设固定范围 | 不设固定范围 | 个体体型差异大 | 使用个人基线和 BCS |
| 布偶猫 | 4.5–6.8 kg | 6.8–9.1 kg | 大型、可能约 4 岁完全成熟 | 仅作群体参考 |
| 英国短毛猫 | 3.6–5.0 kg | 4.5–7.3 kg | 中大型、骨架和肌肉较厚 | 仅作群体参考 |
| 暹罗猫 | 2.3–3.6 kg | 3.6–5.4 kg | 修长、骨架相对较轻 | 仅作群体参考 |

品种参考不能单独用于判断胖瘦。判断优先级为：

`兽医确认的 BCS/目标体重 > 个人历史基线 > 体重趋势 > 年龄、性别、绝育状态 > 品种参考`。

## 4. 生命阶段

| 阶段 | 年龄 | 体重解释重点 |
|---|---|---|
| 幼猫 | 出生至不足 1 岁 | 关注生长轨迹，不套用成年范围 |
| 青年成年猫 | 1–6 岁 | 关注绝育后和成年早期持续增重 |
| 成熟成年猫 | 7–10 岁 | 同时关注增重、减重和 BCS |
| 老年猫 | 超过 10 岁 | 提高对持续减重和肌肉流失的关注 |

## 5. BCS 知识

BCS（Body Condition Score）是体况评分，用观察和触摸评估脂肪储备。它回答的是“这个体重对这只猫是否合适”，而不是“猫有多重”。

| BCS | 解释 | 参考体脂/超重关系 |
|---:|---|---|
| 1–3 | 偏瘦 | 脂肪储备偏少 |
| 4–5 | 理想 | 5/9 常作为理想基准 |
| 6 | 轻度超重 | 约超出理想体重 10% |
| 7 | 超重 | 约超出理想体重 20% |
| 8 | 肥胖 | 约超出理想体重 30% |
| 9 | 严重肥胖 | 约超出理想体重 40% |

BCS 需要观察和触摸肋骨、腰线与腹部，体重秤不能自动测得。用户自评只能用于筛查，兽医确认优先。

## 6. 核心知识条目

### KB-WEIGHT-001：品种参考体重

- 用户问法：英短多重正常？布偶 8 kg 正常吗？暹罗是不是比较轻？
- 所需字段：`breed`、`sex`、`birth_date`、`stable_weight_g`
- 建议字段：`bcs_score`、`personal_baseline_g`
- 回答规则：仅成年猫显示同性别品种范围；中华田园猫不显示固定范围；幼猫使用生长解释。
- 标准答案：品种范围是群体参考，不能单独判断胖瘦，需要结合 BCS、骨架和个体历史趋势。
- 禁止表达：“超过品种上限就是肥胖”“低于下限就是营养不良”。

### KB-WEIGHT-002：当前体重是否正常

- 用户问法：我家猫 6 kg 正常吗？是不是太胖了？
- 所需字段：`stable_weight_g`、`birth_date`、`sex`、`breed`
- 建议字段：`bcs_score`、`personal_baseline_g`、`weight_30d_change_pct`
- 判断顺序：生命阶段 → BCS → 个体基线和趋势 → 性别 → 品种参考。
- 数据不足追问：猫多大、性别、是否绝育、BCS 或肋骨是否容易摸到、最近是否持续增减重。
- 标准答案：不能仅凭公斤数判断，需要结合体况与个人趋势。

### KB-WEIGHT-003：年龄与体重

- 用户问法：猫几岁最容易胖？老年猫变轻正常吗？
- 所需字段：`birth_date`、`daily_weight_g`
- 建议字段：`weight_90d_change_pct`、`bcs_score`、`mcs_score`
- 回答规则：幼猫解释为生长；中年关注增重；老年持续减重不能简单视为正常衰老。
- 风险边界：老年猫持续减重，尤其伴随食欲、饮水、排尿或活动变化时，建议兽医评估。

### KB-WEIGHT-004：性别与体重

- 用户问法：公猫是不是普遍更重？母猫应该多重？
- 所需字段：`sex`、`breed`、`birth_date`
- 标准答案：同一品种中公猫通常体型更大，但性别只是群体影响，不能代替 BCS 和个人基线。
- 禁止表达：“公猫胖一点一定没关系”。

### KB-WEIGHT-005：绝育与体重

- 用户问法：猫绝育后会变胖吗？绝育后三个月胖了正常吗？
- 所需字段：`neuter_status`、`neuter_date`、`sex`
- 建议字段：绝育前后体重、`feeding_method`、`daily_food_g`、`activity_level`、`bcs_score`
- 标准答案：绝育与增重风险增加有关，尤其应观察术后数月的体重、食量和活动变化；并非所有猫都会变胖。
- 产品逻辑：比较绝育附近基线与术后 4、8、12、24 周趋势。

### KB-WEIGHT-006：BCS 是什么

- 用户问法：BCS 是什么？怎么判断猫胖不胖？
- 所需字段：无。
- 标准答案：BCS 是 1–9 分体况评分；1–3 偏瘦、4–5 理想、6–7 超重、8–9 肥胖。需要观察并触摸肋骨、腰线与腹部。
- 风险边界：用户自评为筛查，不替代兽医确认。

### KB-WEIGHT-007：持续增重

- 用户问法：猫最近一直长胖怎么办？一个月胖了很多正常吗？
- 所需字段：`weight_30d_change_g`、`weight_30d_change_pct`、`data_quality_score`
- 建议字段：`neuter_date`、饮食字段、`activity_level`、`bcs_score`、健康事件。
- 回答逻辑：先确认称重数据可靠，再解释摄入增加、绝育后变化、活动减少、换粮和零食等常见因素。
- 风险边界：短期突然增重且无法用饮食解释，或伴随腹部异常、呼吸或精神变化时，建议兽医评估。

### KB-WEIGHT-008：持续减重

- 用户问法：猫最近一直掉体重正常吗？一个月瘦了 200 g 要紧吗？
- 所需字段：`weight_30d_change_g`、`weight_30d_change_pct`、`personal_baseline_g`、`data_quality_score`
- 建议字段：年龄、疾病、食欲、饮水、排尿、呕吐、排便和活动变化。
- 回答逻辑：用百分比解释变化；先排除设备和数据问题；区分计划减重与非计划减重。
- 风险边界：非计划性持续减重，特别是老年猫或伴随其他症状时，应咨询兽医。

### KB-WEIGHT-009：减重计划

- 用户问法：猫减肥一周掉多少合适？减得太快怎么办？
- 所需字段：`personal_baseline_g`、每周体重趋势、`target_weight_g`
- 建议字段：`bcs_score`、疾病、实际食量。
- 标准答案：专业资料通常建议肥胖猫在兽医管理下每周减重约 0.5%–2%；个体目标应考虑疾病和肌肉状态。
- 风险边界：不能通过断食让猫快速减重；食欲明显下降或减重过快需联系兽医。

### KB-WEIGHT-010：饮食与体重

- 用户问法：吃干粮一定更胖吗？自由采食好吗？应该喂多少？
- 所需字段：`food_type`、`feeding_method`、`daily_food_g`
- 建议字段：热量密度、零食、体重趋势和 BCS。
- 标准答案：体重主要受总热量摄入与消耗影响，不能仅凭干粮或湿粮判断；自由采食可能让摄入量难以控制。
- 限制：没有热量密度和理想体重时，不输出精确喂食克数。

### KB-WEIGHT-011：活动与体重

- 用户问法：猫不爱动会胖吗？多运动能减肥吗？
- 所需字段：`activity_level`
- 建议字段：体重趋势、饮食和 BCS。
- 标准答案：活动不足与超重风险有关；活动有助于能量消耗和维持肌肉，但体重管理通常还需要控制总热量。

### KB-WEIGHT-012：老年猫体重下降

- 用户问法：老猫越来越瘦正常吗？十几岁的猫体重下降怎么办？
- 所需字段：年龄、30/90 日趋势、个人基线。
- 建议字段：BCS、MCS、疾病、食欲、饮水、排尿、呕吐和活动。
- 标准答案：老年猫可能出现肌肉和体重下降，但持续减重不应简单归因于衰老。
- 风险边界：建议及时进行兽医评估，特别是伴随饮水排尿变化、食欲变化或精神下降时。

### KB-WEIGHT-013：设备能测什么

- 用户问法：这个猫窝能测体脂吗？能测健康吗？
- 所需字段：无。
- 标准答案：单个体重传感器可测稳定体重、体重趋势、进入次数和停留时长；不能直接测体脂、肌肉量、姿势、身份、心率、疾病或睡眠阶段。

### KB-WEIGHT-014：多猫家庭

- 用户问法：两只猫共用能分清吗？这条体重是谁的？
- 所需字段：`household_type`
- 标准答案：没有摄像头或 RFID 时，单个重量传感器不能可靠区分体重相近的猫。多猫数据需用户确认；一台设备绑定一只猫最可靠。

## 7. 异常时的补充问卷

当系统发现持续增重或减重时，可以询问：

1. 最近食欲增加、减少还是不变？
2. 饮水是否明显增加？
3. 排尿是否明显增加？
4. 是否出现频繁呕吐？
5. 是否腹泻或便秘？
6. 活动量是否下降？
7. 最近是否换粮或调整喂食量？
8. 最近是否绝育、患病、就医或开始用药？
9. 当前变化是否属于兽医指导下的减重计划？

问卷只用于组织信息和决定回答方向，不用于诊断疾病。

## 8. 通用回答边界

所有回答遵循：

- 不仅凭单次重量判断健康；
- 不仅凭品种范围判断肥胖；
- 不把“相关”表达成必然因果；
- 不根据体重变化诊断具体疾病；
- 数据不足时先追问，不输出伪精确结论；
- 优先使用猫自己的历史趋势；
- 用户自评 BCS 低于兽医确认优先级；
- 出现非计划性持续减重或明显伴随症状时建议兽医评估；
- 不提供断食、极端限制饮食等建议。

通用免责声明：

> 本回答用于体重趋势和健康信息参考，不能替代兽医检查或诊断。如果猫咪出现明显食欲、饮水、排尿、呕吐、呼吸、精神或活动异常，请及时咨询兽医。
